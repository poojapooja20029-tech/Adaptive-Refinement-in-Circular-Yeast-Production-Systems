# Adaptive Refinement in Circular Yeast Production Systems

Django-based project for yeast production monitoring, yield prediction, process optimization, and adaptive refinement.

## Setup

1. Create and activate a virtual environment.
2. Install dependencies:
   `pip install -r requirements.txt`
3. Run migrations:
   `python manage.py migrate`
4. Create an admin user if needed:
   `python manage.py createsuperuser`
5. Start the development server:
   `python manage.py runserver`

Then open `http://127.0.0.1:8000/`.

## Notes

- The project includes the dataset and trained model under `yeast/dataset/`.
- The virtual environment and Python cache files are intentionally excluded from this submission package.
